LLM 설정

OpenAI 호환 엔드포인트(/chat/completions)를 사용합니다. OpenAI, OpenRouter, 로컬(Ollama·LM Studio 등) 모두 연결할 수 있습니다. 저장하면 설정이 이 브라우저와 로컬 서버의 .env 파일 양쪽에 반영됩니다. 입력한 API 키가 이 로컬 서버와 LLM 공급자 밖으로 전송되는 일은 없습니다.

저장 위치:
같은 주소로 열 때만 설정이 유지됩니다. file://로 연 탭과 http://localhost 탭의 저장소는 서로 다릅니다.

⚠ 공용 컴퓨터에서는 API 키를 저장하지 마세요.

윤문 규칙과 프롬프트는 im-not-ai (MIT)의 룰북·모놀리스를 뼈대로 삼고, humanizer-ko·patina·yoonmoon을 벤치마킹해 웹용으로 재구성·보강한 것입니다. 출처별 채택 내역은 REFERENCES.md에서 관리합니다. 본 도구는 AI 탐지기 우회를 보장하는 진실성 도구가 아니며, 학술 제출물 등 해당 분야 규정 확인 후 사용하세요.
