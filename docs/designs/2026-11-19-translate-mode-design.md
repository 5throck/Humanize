## Problem

이 프로젝트는 한국어 AI 티 제거에만 집중해 왔다. 그러나 실사용 축 하나가 비어 있었다: 해외 팀이 쓴 **영어 원문을 한국 고객용 자연 한국어로 옮기는** 작업. 이 축의 전문 저장소인 K-Humanizer(2026-11-19 레지스트리 등록)는 "번역 후 AI 티" 문제를 정확히 다룬다 — 번역투 주어 직역(당신·그것), 긴 명사화, 번역투 CTA 등. 우리 A 카테고리(번역투)와 겹치지만 대상이 "영어 원문 번역"이라 트리거가 다르다(규칙 엔진은 한국어 입력만 보므로 커버 불가).

## Change Design

### D1 — engine/prompt.js translate(genre)

K-Humanizer SKILL.md의 핵심 계약을 시스템 프롬프트로 이식:

- **정확성 우선**: "윤문보다 사실 전달이 앞선다" — 독자가 직접 검증하지 못할 수 있다는 upstream 전제.
- **사실·약속 보존 목록**: 가격·통화·할인 조건, 정책(환불·취소·보증), 수치·통계(비교·측정 조건), 날짜·시간대·기한, 인용·코드·식별자 + 부정·예외·한정사("최대"·"약")·확신 수준.
- **추가 금지**: 혜택·성능 주장·긴급성·희소성·판매 훅·문화 참조. 통화·시간대·단위 변환 금지(한국식 표기는 가능).
- **상충 처리 규약**: 원문과 초안이 어긋나면 조용히 판정 금지 — 승인 버전 우선 / 명백 오역은 교정+1줄 보고 / 불명이면 집중 질문 또는 미해결 표시.
- **한국어 우선 구성**: 한국어 어순으로 문장 구성, 병합·분할·재배열 허용(사실·조건 유지), 단어 대 단어 대응 아님.
- **'금지된 단어 없음'**: 통해·제공·진행도 맞으면 정상 — 몫 줄이기 금지. (upstream 어휘 레이어와 같은 철학)
- **레지스터 기본값**: B2B·공지=합쇼체, 소비자 앱=해요체, 버튼·헤드라인=명사구 — 장르별 note로 매핑.
- **출력 계약**: 한국어 먼저, 판정 문구("수정할 부분이 없습니다") 금지, 중대 불일치만 1~2문장 보고, 미해결은 `[자리표시자]`+요청 언어 질문.
- 우리 AI 티 룰북(RULEBOOK)을 **후검 패스**로 결합 — 번역 결과가 A~K 규칙도 통과하게 만들고, 시스템 프롬프트 하나로 끝내 콜마다 재로드 폭발을 피한다(청킹 설계와 일관).

### D2 — UI·파이프라인 통합

- **작업 토글**(윤문 / 번역(EN→KO))을 툴바에 추가. 번역은 LLM 전용이라 규칙 모드에서 선택하면 **자동으로 LLM 모드 전환**+안내 문구. 예시 버튼은 영어 영업 메일 샘플(가격·날짜·정책·조건이 든 것)로 전환된다.
- **입력 가드**: 번역 모드는 영어 입력을 허용(한글 가드는 윤문에만 적용). 규칙 모드+번역 조합은 오류 안내.
- **파이프라인**: 청킹은 언어 무관하게 동작해 긴 영어 원문도 분할 처리. 어휘 힌트(한국어 어색함 대상)는 번역 모드에서 생략. 통계는 EN 원문 대비 before/after가 무의미하므로 변경률·세부 배지를 빼고 결과 한국어의 AI 티 신호·등급만 표시. 패턴 칩은 결과의 잔존 신호를 보여 준다.
- **fidelity**: 번역 모드에서는 수치·단위·자리표시자만 검사(인용 부호·부정은 언어 관습상 합법적으로 변형됨 — upstream "한국식 날짜·금액 표기는 가능"과 같은 선).

### D3 — API·MCP

`/api/prompt`와 `humanize_prompt`에 `mode`(`polish`|`translate`) 파라미터 추가. 도구 수를 늘리지 않고 기존 프롬프트 엔드포인트의 모드 확장 — 에이전트 워크플로("프롬프트를 받고 → 청크별 자기 모델 처리 → merge")는 그대로 유지되며 mode만 바꾸면 번역에도 재사용된다.

## Alternatives Considered

| 대안 | 기각 사유 |
|------|----------|
| 번역을 규칙(A~K)으로 처리 | 번역은 생성 작업 — 규칙 엔진은 한국어 입력의 탐지·수정 도구라 역할이 아님 |
| 별도 MCP 도구(humanize_translate_prompt) 8번째 추가 | mode 파라미터로 충분 — 도구 표면 최소화(ADR-0002 정신) |
| 번역 후 자동 2차 윤문 콜 | 시스템 프롬프트에 룰북 후검을 결합해 1콜로 처리 — 콜 비용 2배·병렬 청킹과 충돌 |
